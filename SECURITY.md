# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within HATH0R-MCP, please follow responsible disclosure guidelines:

1. **Do not create a public GitHub issue.**
2. Send security reports privately to security@bayly.ai or open a confidential advisory via GitHub Security Advisories.
3. Include detailed steps to reproduce the issue, potential impact, and suggested mitigation if available.

We will acknowledge receipt within 48 hours and coordinate a timely fix and release.
